::: tip 💡 📚 学习指南

- **Java 基础**：掌握 Java 概述、基本语法、数据类型、异常处理，重点是面向对象（封装、继承、多态）、多线程与并发、JVM、集合源码
- **Java 高级**：深入 Java 反射、JVM 调优、并发编程高级特性
- **计算机基础**：操作系统、计算机网络、数据结构与算法
- **数据库**：MySQL、Redis 核心知识点与优化技巧
- **Java 框架**：Spring 全家桶（Spring、Spring MVC、MyBatis、Spring Boot、Spring Cloud）
- **分布式**：分布式框架、缓存、消息队列、搜索引擎
- **源码剖析**：主流框架源码分析
- **架构设计**：系统设计与架构面试题
- **场景题**：业务场景面试题
- **面试技巧**：简历优化、HR 面试技巧

:::
