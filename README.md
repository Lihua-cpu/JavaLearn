# 🍵 Java 学习 \& 面试知识库

**基于 VuePress 搭建的全方位 Java 技术学习文档 \+ 面试备考资料库**

本项目是一套**从零入门到高阶进阶、兼顾日常学习与求职面试**的 Java 全栈知识库，全程使用 VuePress 构建，文档结构清晰、检索便捷、沉浸式阅读，专为 Java 学习者、职场开发者、求职面试者打造。

旨在解决大多数人 Java 学习碎片化、知识点零散、面试考点不系统、刷题无总结的问题，打造一份**可长期学习、随时查阅、持续更新**的 Java 一站式技术手册。

## ✨ 项目特色

- **双核心定位**：兼顾**零基础系统学习** \+ **面试资料**，学习、求职一步到位

- **持续更新迭代**：长期维护，持续补充新技术、面试新题型、企业高频考点，适配行业技术迭代

- **开源免费**：所有内容开源共享，无门槛学习、无广告、无付费内容，可自由查阅、收藏、传播

## 📚 文档核心内容

文档覆盖 Java 全阶段学习内容，从基础语法到高阶框架、从源码原理到面试真题，全方位覆盖开发与求职场景，核心模块如下：

- **Java 基础篇**：语法核心、面向对象、集合框架、IO、异常、泛型、反射、枚举等零基础必备知识点，搭配实操案例

- **Java 进阶篇**：多线程并发、JVM 原理、内存模型、垃圾回收、类加载机制、异常调优、IO/NIO 深入解析

- **数据库篇**：MySQL 基础、索引原理、事务隔离、锁机制、SQL 优化、数据库面试高频考点

- **主流框架篇**：Spring、SpringMVC、SpringBoot、SpringCloud 核心原理、源码浅析、实战用法、常见问题排查

- **中间件篇**：Redis、MQ、Nacos、Sentinel 等常用中间件原理、实战与面试考点

- **计算机基础**：网络协议、操作系统、数据结构与算法（Java 实现）

- **面试专项篇**：大厂高频面试题、八股文总结、真题解析、答题思路、项目经验包装、常见坑点避坑指南

- **实战拓展篇**：项目开发规范、代码优化技巧、Bug 排查思路、职场开发经验总结

## 💻 本地运行部署

本项目基于 **VuePress 1\.x** 构建，本地快速启动、编辑、预览文档，步骤简单：

### 1\. 环境依赖

- Node\.js \>= 24\.x

- npm / yarn 包管理工具

### 2\. 克隆项目

```Plain Text
git clone 你的项目仓库地址
cd 项目文件夹
```

### 3\. 安装依赖

```Plain Text
npm install
```

### 4\. 本地启动（开发模式）

```Plain Text
npm run dev
```

启动完成后，访问 `http://localhost:8080` 即可预览文档

### 5\. 打包部署（生产模式）

```Plain Text
npm run build
```

打包后的静态文件生成在 `.vuepress/dist` 目录，可直接部署到服务器、GitHub Pages、Gitee Pages 等平台
